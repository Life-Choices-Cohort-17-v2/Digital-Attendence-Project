# SpySee - Frontend

A modern, intuitive, and responsive frontend for the SpySee application. Built to provide a seamless user experience for time tracking and project management.

---

## About The Project

The SpySee frontend is the client-facing part of our time management suite. It allows users to log in, manage their projects, track their work hours, and view insightful reports on their productivity. This repository contains all the necessary code for the user interface and client-side logic.

---

## Features

-   **User Authentication:** Secure login and registration pages.
-   **Dashboard:** A central hub for users to get an overview of their current tasks and tracked time.
-   **Time Tracking:** Easy-to-use interface to clock in, clock out, and manage time entries.
-   **Reporting:** Visual representation of tracked time through charts and data tables.
-   **Responsive Design:** Fully functional and visually appealing on all devices, from mobile phones to desktops.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- VSCode
- XAMPP
- Make sure Xampp is running before you follow the following next steps

### Installation

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/your-username/insite-frontend.git
    ```
2.  **Navigate to the project directory:**
    ```sh
    cd frontend
    ```
    ```sh
    cd public
    ```
3. **Run PHP:**
    ```sh
    /c/xampp/php/php.exe -S localhost:8000
    ```
