# Digital Attendance System – Backend API

## Overview
This is the **PHP backend** for the Digital Attendance System. It serves as the core logic engine, handling employee authentication, QR-based clock-in/out workflows, dashboard analytics, and external reporting integration (Google Sheets). The backend follows a lightweight MVC-inspired architecture using PDO for database communication.

---

## Technology Stack
- **PHP 8+**
- **MySQL** 
- **Google Apps Script / Google Sheets**
- **Apache**
